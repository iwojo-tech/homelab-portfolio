# Era 4 of 9 — Discovering Self-Hosting

**Ubuntu Server · AdGuard Home · Docker Compose · Home Assistant**

## The next problem
I had used AdGuard on mobile devices and wanted to try AdGuard Home as a network service. I repurposed another Windows laptop as an Ubuntu Server and migrated from Pi-hole to AdGuard Home.

What began as a DNS replacement became a general-purpose home server.

## What changed
- I began running and maintaining multiple services on a headless Linux system.
- I used Docker and Docker Compose for self-hosted applications.
- I added Home Assistant, monitoring tools, and other experiments alongside DNS filtering.
- Managing application configuration, storage, updates, and dependencies became part of routine maintenance.

The question shifted from **“What can replace Pi-hole?”** to **“What else can I self-host?”**

## Skills Applied & Developed
- **Applied:** Network services, DNS, IP connectivity, and systematic troubleshooting.
- **Developed and expanded:** Ubuntu Server administration, Docker Compose, application deployment, persistent data management, and operating multiple services on one host.

## Why the lab grew
Once the server was running several applications, I began thinking more seriously about resource use, uptime, updates, and workloads other people would depend on.
