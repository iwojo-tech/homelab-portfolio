# Era 4 of 9 — Discovering Self-Hosting

**Ubuntu Server · AdGuard Home · Docker**

## The next problem
I had used AdGuard on mobile devices and wanted to try AdGuard Home as a network service. I repurposed another Windows laptop as an Ubuntu Server and replaced Pi-hole with AdGuard Home.

## What changed
The server soon became a place to run more than DNS filtering. I added services, Docker containers, Home Assistant, monitoring tools, and other experiments.

The question shifted from **“What can replace Pi-hole?”** to **“What else can I self-host?”**

## What I learned
**Ubuntu Server · Linux administration · AdGuard Home · Docker Compose · Application hosting · Service management**

## Why the lab grew
As more services shared one host, I found workloads worth running continuously—and began thinking about resource use, persistent data, updates, and availability.
